# Stable Diffusion With Diffusers JP
画像生成AIであるStable Diffusionを簡単に使えるようにしたアプリ。使いやすさを重視。

# 特徴
- Gradioを使ったWeb UI
- ワンクリックで実行
- txt2imgとimg2img
- 日本語プロンプト対応
- 推論ステップ数の指定
- diffusersを使用
- デバイスを自動選択(CPU、Nvidia GPU)
- 生成時間最長約9分(推論ステップ数10、CPUの場合)
